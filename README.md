Nabídka požaduje alespoň dva roky komerční praxe v Pythonu, praktickou zkušenost s AI, znalost AWS, Gitu, CI/CD a Dockeru nebo Kubernetes, vysokoškolské IT vzdělání a komunikativní češtinu. Výhodou je znalost NLU/NLP a zkušenost s dodávkami řešení do podnikového prostředí. Práce počítá se třemi dny týdně na pracovišti v Praze.
