## Pracovní nabídka

[Odkaz na inzerát](<https://eon.jobs.cz/?r=detail&id=2001525518>)

E.ON hledá technického lídra pro zavádění AI do vývoje a modernizace podnikových aplikací. Role se věnuje agentním workflow pro analýzu požadavků a kódu, návrh řešení, implementaci, testování, code review a přípravu nasazení. Zahrnuje integraci AI nástrojů do vývojového prostředí, CI/CD a týmových postupů.

Důležitá je praktická zkušenost se software engineeringem a AI coding agenty, znalost životního cyklu podnikových aplikací, DevOps, bezpečnosti a řízené automatizace. Součástí práce je validace AI výstupů, sledovatelnost změn, schvalování a měření dopadu na kvalitu a rychlost vývoje. Role zahrnuje odborný rozvoj vývojářů a Tech Leadů prostřednictvím workshopů, pairingu a mentoringu; personální odpovědnost zůstává liniovým manažerům.

Pozice je na plný úvazek; nabídka uvádí Prahu, Brno a České Budějovice. ID pozice E.ON: 246723.
