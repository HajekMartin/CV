## Pracovní nabídka

[Odkaz na inzerát](<https://www.jobs.cz/rpd/2000258539/>)

Veeam Software (Czech Republic) s.r.o. hledá C# vývojáře pro produktové týmy v oblasti virtualizace. Náplní je vývoj a údržba funkcí, implementace větších částí produktu a spolupráce na návrhu komponent a architektury.

Nabídka uvádí C#, .NET 8, Windows/Linux, Microsoft SQL Server, PostgreSQL a vícevláknové programování. Požaduje alespoň tři roky komerčního vývoje produktů pro široký trh, znalost .NET, datových struktur, algoritmů, SQL/T-SQL a návrhu softwaru. Angličtina slouží ke spolupráci s mezinárodními týmy; další objektově orientovaný jazyk, například C++ nebo Java, je výhodou.

Pozice je na plný úvazek v Praze. Práce na dálku je možná pouze při pobytu v České republice.
